# Telegram Bot (Bot_VIP)

Простой Telegram-бот на Python.

## 🚀 Установка и запуск

1. Клонируйте репозиторий:
   git clone https://github.com/Bandito2025/Bot_VIP.git
   cd Bot_VIP

2. Установите зависимости:
   pip install -r requirements.txt

3. Скопируйте шаблон настроек и укажите свой токен:
   copy .env.example .env

4. Запустите бота:
   python bot.py
