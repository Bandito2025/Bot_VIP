## 📌 О проекте

**Telegram VPN Bot (Enterprise Edition)** — высокопроизводительный модульный Telegram-бот для коммерческой автоматизации VPN-сервисов любого масштаба. 

Архитектура системы объединяет классические панели **3X-UI** и высокоскоростной движок **Web Panel Proxy (WPP v2.8+)**, обеспечивая одновременную работу с передовыми протоколами обхода блокировок: **VLESS (XTLS Reality, XHTTP)** и **Hysteria 2 (UDP-ускорение)**.

Бот спроектирован для отказоустойчивой работы под высокой нагрузкой: включает встроенную защиту от утечек файловых дескрипторов (AutoClose SQLite Connection Factory), поддержку пулов соединений HTTPX и полностью автономный установщик в один клик.

## ✨ Ключевые возможности

### 🌐 Мульти-панельная гибридная маршрутизация
* **Одновременная работа с 3X-UI и Web Panel Proxy**: распределение пользователей по локациям и нодам разных типов без ручной перенастройки.
* **Поддержка протоколов нового поколения**:
  * **VLESS + Reality / XHTTP** — маскировка под доверенный HTTPS-трафик без внешних сертификатов.
  * **Hysteria 2** — максимальная скорость и пробиваемость на нестабильных каналах и мобильных операторах.
  * **Trojan & Shadowsocks** — проверенная совместимость с широким спектром клиентов.
* **Единые универсальные подписки**: генерация динамических Smart-ссылок и QR-кодов, отдающих клиенту весь пул протоколов в зависимости от его приложения (Happ, V2rayN, Shadowrocket, Streisand, Nekobox, Sing-Box, Clash).

### 💳 Автоматизированный биллинг и эквайринг
* **Модуль фонового автоплатежа (`autopay.py`)**: циклическая верификация счетов без задержек и подвисания интерфейса.
* **Поддержка множества платежных методов**:
  * Банковские карты (ЮKassa, Cardlink, WATA, Platega).
  * Криптовалюты (CryptoBot, прямые переводы).
  * Telegram Stars (оплата внутри приложения).
* **Уведомления о продлении**: автоматические напоминания клиентам за 3, 2 и 1 день до окончания срока действия подписки.

### ⚙️ Интерактивные мастера управления (Wizard-система)
* **Мастер серверов (`server_wizard.py`)**: добавление, диагностика задержки (ping), проверка токенов API и отключение нод прямо через инлайн-кнопки бота.
* **Мастер тарифов (`tariff_wizard.py`)**: гибкое создание тарифных планов (периоды, лимиты устройств, лимиты трафика, динамическая привязка к странам).
* **Ролевая модель доступа (`staff_roles.py`)**: разграничение прав (Суперадмин, Администратор, Техподдержка) с протоколированием действий.

### 🛡 Отказоустойчивость и безопасность
* **FD Leak Protection**: встроенный перехватчик `_AutoCloseConn` для SQLite исключает ошибку `[Errno 24] Too many open files`.
* **SQLite WAL-Mode**: режим высокой параллельности чтения/записи для предотвращения взаимных блокировок базы данных.
* **Изолированный Systemd-сервис**: автоматический перезапуск при сбоях и расширенные системные лимиты (`LimitNOFILE=65535`).

### 1. Требования к серверу
* **Операционная система:** Ubuntu 22.04 / 24.04 / 26.04 или Debian 11 / 12
* **Права доступа:** пользователь `root`
